# Study Simulators

Practice exams with unlimited new versions, case-by-case drilling, hints, worked solutions and timed exam simulations.

| Course | Page | What's inside |
|---|---|---|
| MTH 2413 Calculus I | [`calculus/`](calculus/) | Exam 4 (sections 4.4–5.3): graphing with a sketch pad, optimization, linear approximation, L'Hôpital, antiderivatives, FTC |
| ENGR 102 | [`engr102/`](engr102/) | Exam 2 (Lectures 8–13 plus Exam 1 review): code tracing, true/false, fill in the blank, mixed code, code writing |
| CHEM 1309 | [`chemistry/`](chemistry/) | Exam 3 (Chapters 6–8): configurations, periodic trends, bonding, VSEPR, IMFs, with a slip catcher and speed drills |

Each page is a single self-contained HTML file. Progress is saved in the browser's local storage, so nothing is sent anywhere.

The site is served with GitHub Pages from the `main` branch.
